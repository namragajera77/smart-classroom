SMART ONLINE CLASSROOM & MEETING PLATFORM
FEATURE LIST & ENHANCEMENT IDEAS
==========================================

✅ CURRENTLY IMPLEMENTED FEATURES
----------------------------------

1. Authentication & Authorization
   - User Registration (Email + Password)
   - User Login with JWT tokens
   - Role-Based Access Control (RBAC)
   - Teacher Role: Full control
   - Student Role: Limited access
   - Password hashing with bcryptjs
   - Token-based session management

2. Meeting Management
   - Create Meeting (Teacher only)
   - Start/End Meeting
   - Join Meeting using Meeting ID
   - Meeting status tracking (scheduled/active/ended)
   - Participant tracking with join/leave times
   - Attendance logging

3. Real-Time Video Conferencing
   - WebRTC peer-to-peer video/audio
   - Camera on/off toggle
   - Microphone mute/unmute
   - Multi-party video calls
   - Socket.IO signaling server
   - STUN server integration

4. Real-Time Chat
   - Text messaging during meetings
   - Real-time message delivery
   - Participant names displayed
   - Timestamp on messages

5. Behavioral Analytics (Privacy-First)
   - Study duration tracking
   - Idle time detection (2-min threshold)
   - Tab switch counter
   - Break count tracking
   - NO video/audio analysis
   - Post-meeting analytics

6. Machine Learning Integration
   - Random Forest classifier
   - Attention status prediction (focused/moderate/distracted)
   - Engagement score calculation (0-100)
   - Cognitive load determination
   - Personalized improvement suggestions
   - Flask ML service with REST API

7. Analytics Dashboards
   - Student Dashboard: Personal analytics
   - Teacher Dashboard: Class-level analytics
   - Focus Heatmap Timeline (UNIQUE FEATURE)
   - Color-coded focus visualization
   - Individual and class performance metrics

8. User Interface
   - Responsive design
   - Teacher-specific dashboard
   - Student-specific dashboard
   - Meeting room interface
   - Analytics visualization pages
